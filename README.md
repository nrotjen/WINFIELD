# WINFIELD — GitHub Homepage Mockup

A cinematic, luxury-real-estate-inspired static homepage concept for Winfield.

## Run locally
Open `index.html` in a browser, or use VS Code's Live Server extension.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` and `styles.css`.
3. In **Settings → Pages**, select the `main` branch and `/root`.
4. GitHub will publish the site.

## Notes
- The photography currently uses remote Unsplash image URLs so the mockup looks polished immediately without a large image folder.
- For a production site, replace these with properly licensed/self-hosted photography in an `/images` directory.
- The legal/footer architecture is intentionally substantial: Privacy, Terms, Accessibility and Disclosures are represented as real-site destinations without pretending to provide actual legal language.
- All portfolio names and properties are fictional placeholders for the concept.
