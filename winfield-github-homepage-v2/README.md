# WINFIELD — Homepage Mockup v2

This version shifts the concept toward a refined hospitality/lifestyle brand rather than a conventional luxury real-estate marketing site.

The language is intentionally aspirational by implication: the site talks about how people live, gather, arrive, return and feel, rather than repeatedly calling Winfield "luxury."

The visual system uses warm ivory, ink, restrained typography and classical architectural imagery.

## GitHub Pages
Upload `index.html` and `styles.css` to a repository and enable GitHub Pages from the `main` branch `/root`.

## Photography
The draft uses remote Unsplash image URLs as temporary placeholders. For a production concept, replace them with licensed/self-hosted editorial photography. Several image references were selected around Georgian/classical architecture and hospitality to establish the intended direction.
